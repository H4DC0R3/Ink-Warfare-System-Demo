# Painting System Overview

Ink Warfare System uses a render-target based painting workflow. A gameplay hit is converted into a radial paint operation and drawn into a render target used by the painted mesh material.

## High-level flow

1. A weapon, projectile, trace, or gameplay object generates a hit result.
2. The gameplay object calls `IWS Receive Impact`.
3. The paint system receives the hit data and replicates it through the server/multicast path when needed.
4. The hit is stored in the paintable mesh data.
5. The system captures or reuses the mesh unwrap data.
6. The selected paint material draws the hit into the impact render target.
7. The painted mesh material reads the updated impact texture and displays the final paint.

## Important data passed by an impact

| Field | Purpose |
| --- | --- |
| `Hit Result` | Provides the hit component, impact point, impact normal, and target mesh information. |
| `Size` | Defines the radial hit size range. The system interpolates the radius during the hit animation. |
| `Intensity` | Defines the initial strength of the impact. Usually kept between `0.0` and `1.0`. |
| `Speed` | Controls how quickly the hit animation progresses. Higher values finish faster. |
| `Team` | Selects the team ownership/color used by the paint operation. |
| `Paint Material` | Selects the material used to draw this impact into the render target. |

## Paint material

The paint material is now passed through `IWS Receive Impact`. This allows different weapons, projectiles, or gameplay effects to use different paint visuals while still using the same hit-processing system.

The material should provide the parameters expected by the C++ pipeline:

| Parameter | Purpose |
| --- | --- |
| `Unwrap_Tex` or the configured unwrap texture parameter name | Surface position/unwrap data generated by the capture path. |
| `Color` | Team color used by the impact. |
| `Intensity` | Runtime strength of the hit. |
| `Radius` | Runtime radial size of the hit. |
| `Position` | World-space hit position. |
| `Normal` | World-space hit normal. |

The default parameter name for the unwrap texture is controlled by `ImpactUnwrapTextureParameterName` in the config category.

## Config category

The `Config` category usually does not need to diverge much from the values used by `BP_IWS_PS_InkHits` in the demo. In most projects, the default demo values are a good baseline. Change them only when a project needs a different unwrap resolution, different render target behavior, or a custom material parameter name.

## Scoring

The plugin also contains helpers for team score and area score calculation. These use render-target reads and team score materials to convert painted areas into team score values. The exact scoring rules can be adapted by the game mode or gameplay framework using the plugin.
